# RevenueCat + Stripe configuration

Stripe remains ShiftNote's billing engine and Customer Portal. RevenueCat imports the four external Stripe subscriptions and controls the `pro` entitlement. The Supabase Auth UUID is the RevenueCat App User ID.

## Required environment variables

- `NEXT_PUBLIC_REVENUECAT_WEB_API_KEY`: the public SDK key for the RevenueCat Stripe Web app.
- `NEXT_PUBLIC_REVENUECAT_ENTITLEMENT_ID=pro`: public entitlement identifier used by the Web SDK.
- `REVENUECAT_STRIPE_APP_PUBLIC_API_KEY`: the Stripe app public API key used server-side with `POST /v1/receipts`.
- `REVENUECAT_SECRET_API_KEY`: a RevenueCat V1 secret project API key, stored server-side only.
- `REVENUECAT_PRO_ENTITLEMENT_ID=pro`: server entitlement identifier.
- `REVENUECAT_WEBHOOK_AUTH`: a new random secret token entered as the webhook Authorization value.
- `REVENUECAT_WEBHOOK_SIGNING_SECRET`: the webhook HMAC signing secret generated by RevenueCat.

## RevenueCat dashboard

1. Create or select the ShiftNote project and add a Stripe Web app.
2. As project owner, connect the same live Stripe account through the RevenueCat Stripe app.
3. Create a Stripe web configuration and enable external purchase tracking.
4. Set App User ID detection to read the Stripe metadata key `supabase_user_id`.
5. Import all four Stripe products, selecting their corresponding recurring prices.
6. Create entitlement `pro` and attach all four imported products:
   - Monthly
   - Six Months
   - Promotional Six Months (Discount)
   - Promotional Six Months (Retention)
7. Enable Track new purchases from server-to-server notifications. Prefer recognizing subscriptions after the invoice is paid.
8. Configure the Stripe Customer Portal management URL.
9. Add webhook URL `https://YOUR_DOMAIN/api/webhooks/revenuecat` for production events. Set Authorization to `Bearer <REVENUECAT_WEBHOOK_AUTH>` and enable HMAC signing; store its secret as `REVENUECAT_WEBHOOK_SIGNING_SECRET`.
10. Restart/redeploy after adding environment values, then send a dashboard test webhook and restore one existing Stripe subscriber.

RevenueCat's Web SDK cannot directly restore an external Stripe purchase. ShiftNote's Restore Purchases action securely re-posts the authenticated user's Stripe subscription ID, then refreshes RevenueCat Customer Info.
